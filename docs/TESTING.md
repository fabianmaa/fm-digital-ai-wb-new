## 3. Contact form — the contract, exactly as implemented

### 3.1 Mocked submission (request shape verified)

The browser was pointed at the real form; the network call was intercepted and fulfilled with
`{ "success": true }` so the request could be inspected without touching Notion. **All five
fields were typed for this capture** (the form itself only requires name and email); the
values below are the exact payload recorded from that run.

```json
{
  "url": "https://fm-digital-web-api.onrender.com/submit-contact",
  "method": "POST",
  "headers": {
    "accept": "application/json",
    "content-type": "application/json",
    "origin": "http://localhost:5173"
  },
  "body": {
    "name": "Maria Gonzalez",
    "email": "maria@example.com",
    "phone": "(407) 555-0134",
    "website": "example-clinic.com",
    "message": "Calls after 5 p.m. and Monday no-shows."
  }
}
```

Result: **success panel shown** (“Got it. Thank you.”). The endpoint, method and the five
field names match the API exactly; no extra fields are sent. (Only the relevant request
headers are shown above; the captured `user-agent`/`sec-ch-ua` headers are omitted.)

### 3.2 Honeypot

With the hidden `website1` field filled programmatically, the form displayed “Something went
wrong. Please try again.” and **no request left the browser** (`requestSent: false`).

### 3.3 Localhost and CORS — expected failure, documented

From `http://localhost:5173`, the browser sends the request and the API's preflight response
contains `Access-Control-Allow-Origin: https://fmdigitalai.com`. The browser blocks the call
before any data is posted to Notion:

```text
Access to fetch at 'https://fm-digital-web-api.onrender.com/submit-contact' from origin
'http://localhost:5173' has been blocked by CORS policy: Response to preflight request
doesn't pass access control check: The 'Access-Control-Allow-Origin' header has a value
'https://fmdigitalai.com' that is not equal to the supplied origin.
```

Evidence: request → `net::ERR_FAILED`; our UI shows “We could not send it.” and a retry.
**This is not an end-to-end submission and is not presented as one.** The true end-to-end test
must happen on `https://fmdigitalai.com` after deployment, or earlier only if the owner himself
changes the API's allowed origins.

### 3.4 Spanish form

The `/es/contact` page renders the same component with Spanish copy:
`Nombre completo *`, `Enviar mi solicitud`, and the Spanish heading — all from
`src/constants/copy.ts`.

## 4. Language checks

- English is the default for every path without `/es`.
- Switching language changes the path, the `<html lang>` attribute, the document title, meta
  description, canonical, hreflang pair and every visible string.
- The copy guard found **0 empty translations** and **0 jargon hits** across 560 strings.
- Six strings are identical in both languages by design: “Blog” (`footer.blog`), “Legal”
  (`footer.legalTitle`, `sitemap.legalTitle`), “Cookies”, the `404` label and the name
  placeholder `María González`. No brand name is in this list — brand names are identical too,
  but the guard treats them as proper nouns and excludes them.
- No duplicated Spanish component or page tree exists: `/es/...` renders the same components
  with a different dictionary value.
- A scan of all 14 Spanish pages for common English interface strings (Free audit, Our
  process, Send my request, etc.) returned no English leftovers; “Blog” and “Legal” are the
  correct Spanish labels too.

## 6. Performance notes

- Fonts are self-hosted: 296 KB total for three woff2 files, preloaded, `font-display: swap`.
- The hero is a scroll-scrubbed video (desktop, no reduced motion): a 74 KB WebP poster paints
  first, then the scrub video streams progressively behind a progress ring; mobile, tablet and
  reduced-motion visitors get a static settle frame and never fetch the video.
- The hero settle subcopy is the exact approved EN line: "We help clinics, restaurants and
  local businesses across Central Florida answer every call and message, fill their calendars,
  and get found first — so the business keeps growing. In English and in Spanish." (ES in
  `copy.ts`, `home.hero.lead`).
- The hero activity card crossfades four glass states (phone / answered / table booked / AI
  follow-ups) with line icons and a pulsing ring + voice-bar micro-animations; labels live in
  `copy.ts` (`home.hero.activity`) and the card is hidden on the static fallback and mobile.
- Content images are WebP at 800/1600 px; 800 px versions are 12–98 KB.
- No third-party scripts, no analytics, no cookie banner, no runtime font CDN.
- The build is a single JS chunk (145 KB gzip); route-level code splitting is the obvious next
  optimization if the bundle grows.
- Motion is limited to transform/opacity. Worst-case simultaneous `backdrop-filter` surfaces
  in one viewport is five (the four dark `glass-card-dark` service cards plus the frosted
  header) — an accepted trade for the frosted cards, each a light blur over a mostly-static
  section; ambient orbs are CSS-only and paused under reduced motion.

## 7. Known limitations

1. **CORS**: real submissions can only be tested on the production domain (section 3.3).
2. **SPA metadata**: titles/canonical/hreflang are applied client-side; a crawler that does not
   execute JavaScript sees only the generic title in `index.html`. The sitemap and robots file
   are static and complete.
3. **404 status**: unknown routes render the 404 page but the static rewrite returns HTTP 200
   (documented in `docs/URLS.md`).
4. **Contact details**: no phone, email, street address or secondary channel is published. The
   audit form is the only contact route (D-13, D-42).
